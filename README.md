## Проект: Spotify 2.0 🎶

**Spotify 2.0** — это десктопное react-приложение для прослушивания музыки с возможностью поиска и добавления треков в плейлисты, созданное по подобию Spotify.


🌐 Просмотр:
[Spotify 2.0](https://adamchereshniuk.github.io/Spotify-2.0/?q=)

### 🚀 Установка:

Установка зависимостей:
```
npm install
```
Запуск сервера разработки:
```
npm run dev
```
Запуск production сборки:
```
npm run build
```

### 🛠️ Технологии:

- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Sass](http://sass-lang.com/)
